## What is this mod?

Mas Effects aims to overhaul Minecraft PvP visually,
making it more appealing while keeping if fair for other players! <br>
The original version was created by Masuno, this is supposed to be a maintained Port for newer versions.

### Requires:
- [Ukulib 2.0.0](https://modrinth.com/mod/ukulib) or higher
- Fabricloader 0.18.3 or higher
